## Nashville Housing Data Cleaning Project

## Overview

This project focuses on cleaning and preparing the Nashville Housing dataset using SQL Server.

## Tools

* SQL Server
* DBeaver
* SQL

## Data Cleaning Steps

* Standardized the sale date format
* Filled missing property addresses
* Split property and owner addresses into separate columns
* Changed `Y/N` values to `Yes/No`
* Identified and removed duplicate records
* Removed unused columns

## Goal

The goal of this project is to practice SQL data cleaning and prepare a dataset for further analysis.
